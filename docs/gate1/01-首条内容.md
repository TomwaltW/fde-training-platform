# 首条内容:「我在第三句话就报了价」(草稿)

> **草稿,给作者改写用。** 下面的文字是骨架,不是成稿:语气、细节、结论都要换成你自己的。`【占位:…】` 是只有你能填的地方——这条内容按方案 6.1 是**你本人的翻车实录**,占位处空着就发,等于发了一条没有主人的广告。
>
> 对应方案 6.1 的 L0、6.2 的「小红书、即刻:对话截图式的翻车实录」、附录 E 第 3 天「写第一条内容"我在第三句话就报了价"并发布,挂候补表单」。它只回答一个问题:**有没有人对"FDE 模拟"感兴趣**。数的是发布后 7 天内的候补人数,判定见 [`05-第一关判定.md`](./05-第一关判定.md)。

## 0. 发之前先守住的三条

1. **引号里的每句台词都要出自你真实的对话记录。** 下文引用的老板台词来自四处公开内容:场景简报里的开场白、周总催演示的那句(压力时刻:开场阶段跟周总聊满两个来回、还没离开会议室去找别人时才抛出来;一上来就去找别人的玩家听不到)、方案 3.3.6 的「十天一万八」对照、承诺账本在汇报阶段的回放。你实际玩出来的台词不一样,就改成你的原话;没发生过的,删掉。翻车实录里编一句对话,这条内容就不成立了。
2. **不剧透。** 能写的只有:开场白、简报(公司约 60 人、日均约 300 票、一天 6 小时)、你自己报的「十天、一千八一天、一共一万八」、老板复述并记账、下午那句「你上午说十天、一万八,现在怎么又变了?」、复盘标签「先报价后看货」。**不写**这家公司真正卡在哪、复盘里写的"你当时还不知道什么"具体是什么、见到了谁、拿到了什么资料。结论只停在"我还没看过任何一张单据就报了价"。发布前按第 7 节自查一遍。
3. **AI 生成内容要标明**(方案 8.2 第 3 条)。截图里保留对局页的「对话内容由 AI 生成」标识;自己拼的对话图、封面,底部加一行「场景、公司、人物均为虚构 · 角色台词由 AI 生成」。

**截图守则**

## 6. 候补入口:网站上线之前怎么办

### 6.1 依赖链

内容里的候补链接本该是 `https://<域名>/waitlist?from=xhs`(README「内测运营」,即刻用 `?from=jike`)。但这要求网站已经部署;部署在内地服务器上必须先完成 ICP 备案,管局审核 1–20 个工作日 [方案 8.2 第 1 条,S11]。备案第 1 天提交,也赶不上第 3 天发首条内容。所以**首条内容大概率要用过渡表单**,第一关的候补人数也就从表单里数。

### 6.2 过渡表单

- **用国内的表单工具**(腾讯问卷、金数据、问卷星、飞书问卷任选一个)。海外表单在大陆打开不稳定,会白白丢人。
- **字段照站内候补表单来**,以后迁移不用对口径:

| 字段 | 必填 | 写法 |
|---|---|---|
| 邮箱 | 是 | 邀请码以后发到这里 |
| 你的身份 | 否 | 单选,选项措辞照站内:在做 FDE / 解决方案;在职,想转 FDE;学生;招聘或培训负责人;其他 |
| 想用它做什么 | 否 | 文本,提示语照站内:"比如:下个月要去客户现场,想先练练怎么问需求" |
| 从哪看到的 | 是 | 单选:小红书 / 即刻 / 朋友转发 / 其他。以后每发一条新内容,加一个选项区分是哪一条(见 02) |
| 愿意参加试玩访谈吗 | 否 | 单选"愿意,留微信号"+ 文本框。这是 L1 试玩者的来源之一(见 03) |

- 来源也可以用表单工具的"链接参数"预填,每个渠道发一条不同的链接——各工具支不支持、参数怎么写【待验证】。必填单选题最稳,先用它。
- **表单说明里写清用途**(个人信息最小化,方案 8.2 第 9 条),措辞照站内:"邮箱只用来给你发邀请码,以及统计候补名单里后来有多少人注册、购买(只看人数),不做营销推送。"再加一句:"留微信号的,只用来约试玩时间。想删除登记,发邮件到【占位:你的邮箱】。"
- 表单要"同一邮箱只能提交一次"就打开;打不开也没关系,判定时按邮箱去重。

### 6.3 小红书上放在哪

小红书限制站外链接、二维码和联系方式,被判导流会限流,规则经常调整【待验证:发布前看一眼当时的社区规范】。常见的三个放法,选一个,别同时用:

1. 主页简介写"FDE 训练场 内测候补:见置顶笔记评论";
2. 置顶评论放表单链接(文字链接点不开,对方要复制);
3. 正文写"评论区扣'候补'",再逐个私信发链接——量大时很累,私信能不能带链接也【待验证】。

即刻没有这个问题,正文直接放链接。

### 6.4 网站上线后,怎么把表单里的人迁进来

**管理页的候补名单不支持导入**(本仓库核对过:只能导出 CSV;"给候补名单发邀请码"只认已经在站内名单里的邮箱)。所以这批人**手动邀请**:

1. 在 `/admin` 的「生成邀请码」里,数量填表单里去重后的人数(一次最多 100 个,多了分几次),每个可用次数填 1,备注填"问卷第一批";想按人追踪,就逐个生成、备注写"问卷:<邮箱>"。
2. 给每人发自己的登录链接:`https://<域名>/login?invite=<邀请码>&email=<邮箱>`——登录页会自动填好邀请码和邮箱(和站内邀请邮件里的链接同一个格式)。手拼链接时邀请码和邮箱都要先做 URL 编码:邮箱里的 `+`(常见的别名写法)不编码会被读成空格,预填的邮箱就错了,要写成 `%2B`;站内邀请邮件的链接是自动编码过的。配了 SMTP 也不会替你发,因为他们不在站内名单里;用邮件或微信逐个发。
3. 邀请码在对方验证通过时才消耗,输错邮箱不会作废。

这么做的代价,判定时要记着:

- 这批人**不会出现在站内候补名单和来源统计里**,管理页「继续 / 转向 / 放弃」看板的第一关人数里也没有他们。**第一关的人数以表单导出为准**(按邮箱去重),看板只在站点上线后的内容里用。
- 第三关(W8,「候补名单到预售付费的转化」)也一样:看板只拿站内候补名单算,分子分母里都没有这批人。到 W8 判第三关时,用表单导出的邮箱对一遍管理页兑换码列表里的兑换人,手算这批人的转化;或者先把导入功能做了(见下一条)再看看板。
- 另一个办法是请他们到 `https://<域名>/waitlist?from=form` 重新登记——会进站内名单,但登记时间是重新登记那天,落不进首条内容的 7 天窗口;而且要对方再动一次手,一定会掉人。只在你想让这批人进站内名单统计时用,别当主路径。
- 想让表单名单直接进站内候补名单,要给管理页加一个导入功能。这是工程上的活,不在这份草稿里。

2. 剧透:把待发的文字存成仓库根目录下的 `草稿.txt`(查完删掉,别提交),在仓库根目录跑本节末尾那段脚本。它从 `scenario.yaml` 里现取要查的词和数(自查清单本身不抄这些词和数,免得清单变成剧透)。有 `tools/docgen/.venv`(按 `docs/ci.md` 建,装了 PyYAML)就用它解析 YAML;没有就用系统的 `python3` 按正则读,读不全会报错退出,不会假装"未命中"。输出共五行:
   - 第 0 行(括号里):读到了几个金丝雀词、几个隐藏数字。是 0 或者明显偏少,下面三行都不能信。
   - 第 1 行,金丝雀词(不分大小写):命中就删。
   - 第 2 行,场景隐藏数据(真值和事实)里出现过的阿拉伯数字:不是你自己的分数、轮次、人数,就删。
   - 第 3 行,其余阿拉伯数字:逐个确认是你自己的(比如分数)。
   - 最后一行是提醒。

   公开的数字只在原来的上下文里放行:"60 人""300 票""6 小时""10 天",以及 1800、18000、"1.8 万"(一千八、一万八写成阿拉伯数字)。同一个数换了上下文照样列出来,比如"10 万"会落在第 2 行。全角数字、千分位逗号(18,000)先统一再查。
3. 数字:正文里除了十天、一千八、一万八、约 60 人、日均约 300 票、6 小时,不应出现场景里的任何其他数字。脚本只认阿拉伯数字,汉字写的数字要自己读一遍。
4. 结论没有越过"我还没看过任何一张单据就报了价"。读一遍,看有没有哪句在暗示问题到底出在哪;诊断类的说法脚本查不出来。
5. 截图按第 3 节的守则裁过,AI 生成标识在画面里。截图里的字脚本也查不到。

第 2 项的脚本(整段复制进终端;02 的两条发之前也用它):

```bash
PY=tools/docgen/.venv/bin/python; [ -x "$PY" ] || PY=python3
"$PY" - 草稿.txt <<'EOF'
import re, sys, unicodedata
t = unicodedata.normalize('NFKC', open(sys.argv[1], encoding='utf-8').read())
t = re.sub(r'(?<=\d),(?=\d{3}(?!\d))', '', t)  # 18,000 → 18000
src = sys.argv[2] if len(sys.argv) > 2 else 'scenarios/freight-docs/scenario.yaml'
y = open(src, encoding='utf-8').read()
try:
    import yaml
    d = yaml.safe_load(y)
    can, how = [], 'PyYAML'
    def walk(o):
        if isinstance(o, dict):
            for k, v in o.items():
                if k == 'canaries':
                    can.extend(str(x) for x in (v if isinstance(v, list) else [v]))
                walk(v)
        elif isinstance(o, list):
            for v in o: walk(v)
    walk(d)
except ImportError:
    how, can, keys = '正则(没装 PyYAML)', [], 0
    lines = y.splitlines()
    for i, ln in enumerate(lines):
        m = re.match(r'(\s*)(?:-\s+)?canaries:\s*(.*?)\s*(?:#.*)?$', ln)
        if not m: continue
        keys += 1
        ind, rest, got = len(m.group(1)), m.group(2), []
        if rest.startswith('['):
            j, buf = i, rest
            while ']' not in buf and j + 1 < len(lines):
                j += 1; buf += ' ' + lines[j].strip()
            got = [x.strip() for x in buf[1:buf.index(']')].split(',')]
        elif rest:
            got = []  # 别的写法,下面按"没读到"报错
        else:
            for nx in lines[i + 1:]:
                b = re.match(r'(\s*)-\s+(.+?)\s*(?:#.*)?$', nx)
                if not b or len(b.group(1)) <= ind: break
                got.append(b.group(2))
        got = [x.strip('\'"') for x in got if x.strip('\'"')]
        if not got:
            sys.exit(f'第 {i + 1} 行的 canaries 没读出来,请装 PyYAML 再跑(见 docs/ci.md)')
        can += got
    if keys != len(re.findall(r'(?<![\w-])canaries\s*:', y)):
        sys.exit('有 canaries 不是一行一个键的写法,正则读不全,请装 PyYAML 再跑(见 docs/ci.md)')
if not can:
    sys.exit('scenario.yaml 里一个金丝雀词都没读到,不能当"未命中":检查文件或装 PyYAML 再跑')
# 隐藏数据按顶层键取 truth、facts 两段原文(连注释),不依赖键的先后顺序
blocks = {m.group(1): m.group(0) for m in re.finditer(r'(?ms)^([A-Za-z_]+):.*?(?=^[A-Za-z_]+:|\Z)', y)}
if 'truth' not in blocks or 'facts' not in blocks:
    sys.exit('scenario.yaml 里没找到顶层的 truth 或 facts,脚本要跟着改')
secret = blocks['truth'] + blocks['facts']
num = r'(?<![\d.])\d+(?:\.\d+)?'
hidden = set(re.findall(num, secret))
# 公开的数字只在它的上下文里放行:"10 天"放行,"10 万"照样列出来
ok = [r'60\s*多?\s*人', r'300\s*多?\s*票', r'6\s*个?\s*小时', r'10\s*个?\s*(?:工作)?\s*天',
      r'1800(?![\d.])', r'18000(?![\d.])', r'1\.8\s*万']
scan = t
for p in ok: scan = re.sub(r'(?<![\d.])' + p, ' ', scan)
nums = set(re.findall(num, scan))
print(f'(用{how}从 {src} 读到金丝雀词 {len(can)} 个、隐藏数据里的数字 {len(hidden)} 个)')
print('1 金丝雀词(命中就删):', [x for x in can if x.lower() in t.lower()] or '未命中')
print('2 场景隐藏数据里有的数字(不是你自己的分数、轮次、人数就删):', sorted(nums & hidden) or '未命中')
print('3 其他阿拉伯数字(确认是你自己的):', sorted(nums - hidden) or '无')
print('汉字写的数字、诊断类的说法、截图里的字,这段都查不出,按第 3、4、5 项人工过一遍。')
EOF
```
